# KurageVP 引き継ぎメモ for 192.168.0.3 Codex

## 目的

Kurage Voice Pro (`kuragevp`) を 192.168.0.3 サーバで開発する。

このプロジェクトは、URLから動画を取得し、音声抽出、文字起こし、翻訳、翻訳音声生成、字幕合成、吹き替え動画生成を行い、生成結果を Kurage の動画として公開する。

## リポジトリ

```bash
git clone git@github.com:katsushi2441/kuragevp.git
cd kuragevp
git checkout main
git pull origin main
```

既にclone済みなら:

```bash
cd /home/kojima/work/kuragevp
git fetch origin
git checkout main
git pull --rebase origin main
```

## 現在の重要仕様

- Web画面は `web/kuragevp.php`
- APIは FastAPI で `backend/main.py`
- 処理本体は `backend/pipeline.py`
- APIポートは `18302`
- 生成はRQDB4AIではなく、Kurageと同じ直接API方式
- `kuragevp.php` が `/generate` を叩き、`/status/{job_id}` をポーリングする
- X動画取得は `yt-dlp` ではなく、UMedia風に `api.fxtwitter.com` から動画URLを取得して `curl` で保存する
- WhisperはCPU/int8がデフォルト

## Kurage公開データ登録

KurageVPは生成完了時に、Kurageの公開用storageへJSONと動画を登録する。

現在、Kurage画面で表示させるために以下をJSONへ入れる。

- `tweet_text`: 元投稿本文
- `tweet_author`: 投稿者ID
- `tweet_author_name`: 投稿者名
- `translated_text`: 翻訳済み台本
- `script.scenes[].narration`: Kurage画面の「脚本」に表示される翻訳台本

既存の修正コミット:

```text
b52c7f2 Register source post and translated script metadata
```

この方針ならKurage本体を編集せず、画面に元投稿と台本を表示できる。
